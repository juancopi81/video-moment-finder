Bring these cards with you

  1. Download the CSV, or use the companion .csv file. Choose UTF-8, comma separator, and double-quote quoting in your importer.
  2. The first row contains Front, Back, Tags. Skip it or select “first row is a header.” Map Front and Back to a basic card; map Tags if your app supports it. In Anki, turn off “Allow HTML in fields.”
  3. Fields are plain text. Each back includes scope, source timestamps, and reasoning where applicable. Choose an importer that supports quoted multiline fields, and preview a card before importing the whole deck.
  4. Formula-like text is prefixed with an apostrophe for spreadsheet safety. Some card importers display this character literally. The original text is retained in the companion JSON; do not remove the safety prefix in a spreadsheet.

The export does not set due dates, intervals, review history, or scheduling preferences.
