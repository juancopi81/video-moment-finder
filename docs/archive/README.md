# Archive Policy

This directory stores historical documentation snapshots.

## Scope

- Time-bounded research notes.
- Historical roadmap snapshots.
- Any retired planning/status docs kept for reference.

## Authority

Files in `docs/archive/` are **historical and non-authoritative**.
Active project behavior and workflow are defined by root docs:

- `README.md`
- `PROJECT_SPEC.md`
- `ROADMAP.md`
- `STATUS.md`
- `AGENTS.md`
- `CLAUDE.md` (shim)

## Naming Convention

Use descriptive names with a date suffix when practical:

- `TOPIC_YYYY-MM.md`
- `TOPIC_YYYY-MM-DD.md`

Examples:

- `RESEARCH_QWEN3_VL_2026-01.md`
- `ROADMAP_2026-03-05.md`
